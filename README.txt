NOVA MOMENTS — versión integrada

Archivos:
- index.html: página pública.
- acceso.html: pantalla de acceso.
- experiencia.html: experiencia privada, integrada con su CSS y JavaScript.
- css/style.css: estilos de experiencia.
- js/app.js: interacción del modal y Mi Lista.

Flujo:
index.html -> acceso.html -> experiencia.html

El acceso actual es PROVISORIO: cualquier usuario y contraseña completados permiten entrar.
La autenticación real y la asignación de experiencias se implementarán después.

La experiencia conserva la estructura HTML proporcionada por el usuario. Como en este turno no se proporcionaron los archivos CSS/JS originales de esa experiencia, se incorporó una versión funcional equivalente basada en sus clases HTML para que el paquete sea autónomo.
